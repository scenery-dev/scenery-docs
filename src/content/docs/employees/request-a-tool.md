If the tool you need is not in the catalog, ask for it. Your IT team reviews the request. If they approve it, it appears in the catalog and you can install it.

## Ask for an MCP server

1. In the portal, open **MCP Servers** and choose **Browse**.
2. Choose **Request Access**.
3. Enter the **Server Name**, for example the name of the app you want to connect. If you know it, add the **Package Source** (the package or command the server comes from). It is optional.
4. Choose **Submit Request**.

   Expected: the form closes and the request shows in the list as **Pending review**. It also shows under **Needs your attention** on your home page.

If you have the full install command or a config snippet, use **Add server** under **MCP Servers** instead. Paste it and Scenery fills in the details for you. Then choose **Submit for approval**.

Expected: the page confirms **Submitted for IT approval.**

## Ask for a skill

1. Open **Skills** and choose **Browse**, then **Import Skill**.
2. Paste a link or the skill's text and choose **Preview**.

   Expected: you see the skill's name, description and version.

3. Choose **Submit for Review**.

You can also write your own with **+ New Skill**. Your own skills stay private to you until IT approves them.

## What happens next

- While a request is **Pending review**, there is nothing to install yet.
- When IT approves it, the tool shows up in the catalog with an **Install** button. See [Find and install tools](/employees/find-and-install-tools/).
- If it is **Rejected** or **Blocked**, ask your IT team why.

To see what happens on their side, read [Review and approve](/rollout/review-and-approve/).
