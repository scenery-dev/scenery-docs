The Scenery runner is open source under the Apache 2.0 license. It is the part of Scenery that runs on your employees' laptops, so you can read what it does.

- Source: [github.com/scenery-dev/scenery](https://github.com/scenery-dev/scenery)
- Security policy and how to report a vulnerability: [SECURITY.md](https://github.com/scenery-dev/scenery/blob/main/SECURITY.md)

The control plane behind it is not open source. Its behavior is described in these docs and in the [API reference](/reference/api/).
